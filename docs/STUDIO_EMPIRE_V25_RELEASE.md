# STUDIO EMPIRE v0.25 — Feature expansion and management reconstruction

## Scope

Existing repository: `shepgleis-create/Studio-Empire`.

## Implemented in code

- One new management console with 20 actual game management pages across Studio, Games, People and Business.
- Responsive desktop sidebar, mobile bottom-category navigation, horizontally scrollable secondary tabs, a contextual studio entry button, a single consistent card/input/control design, and save-backed display values.
- Franchise registration from released games (cash fee), franchise promotion with cooldown, archived/reactivated intellectual property, and sequels connected to the ordinary project development/release lifecycle.
- Business financing with three loans, reputation restrictions, maximum two simultaneous loans, daily amortizing repayment, and optional early settlement.
- Five levels of equipment investments. Computer, audio and server improvements change actual project progress; QA improvements reduce defects; the lounge helps employee morale/energy. Era, office tier, quantity limit, and money restrictions apply.
- Four industry events with historically restricted availability, attendance costs, audience/hype gains, community-beta bug reduction, and cooldown.
- Existing workflows remain available: continuous day-by-day clock, genre-aware title generator, game development, research, staff, culture, office purchasing, rival companies, subsidiaries, pricing, publishing and saves.
